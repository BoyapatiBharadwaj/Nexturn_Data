# Pharmacy Sales and Stock Monitoring

## 1. Project Overview

This Apache Spark mini-project implements a simple pharmacy sales and inventory monitoring system using Scala 2.12, Apache Spark 3.5.9 and sbt. The application processes medicine master data and pharmacy sales/restock events to calculate current stock, identify medicines requiring attention, and demonstrate core Spark RDD, Pair RDD, Spark SQL, DataFrame/Dataset, partitioning, persistence, accumulator and DStreams concepts.

The implementation is intentionally limited to the academic problem scope. It does not include a web frontend, database, authentication, REST API, machine learning or cloud deployment.

## 5. Stock Business Rule

```text
Current Stock = Initial Stock - Total Sales + Total Restocking
```

Status rules:

```text
current_stock <= 0
    STOCK_OUT

current_stock < reorder_level
    BELOW_REORDER

current_stock <= 2 * reorder_level
    AT_RISK

otherwise
    ADEQUATE
```

## 8. Streaming

`StreamingProcessor.scala` uses classic Spark Streaming DStreams, not Structured Streaming.

Configuration:

- micro-batch interval: 5 seconds
- sliding-window length: 15 seconds
- sliding-window slide: 5 seconds
- state management: `updateStateByKey`
- checkpoint directory: `data/streaming/checkpoint`
- input directory: `data/streaming/input`
- output directory: `data/output/streaming`

New CSV files can be copied into the streaming input directory after the application starts.

## 12. Compile and Run

From Ubuntu:

```bash
cd ~/spark-mini-project
sbt clean compile
sbt run
```

The default main class is `BatchProcessor`.

Run the streaming program with:

```bash
sbt "runMain StreamingProcessor"
```

## 13. Streaming Test

Start the streaming application first, then in another terminal:

```bash
cd ~/spark-mini-project
cp data/streaming/sample/stream_batch_01.csv data/streaming/input/
cp data/streaming/sample/stream_batch_02.csv data/streaming/input/
```

Inspect outputs:

```bash
find data/output/streaming -maxdepth 2 -type f | sort
```

Stop the DStreams application with `Ctrl+C`.

For a clean first streaming run:

```bash
rm -rf data/streaming/checkpoint/*
rm -rf data/output/streaming/*
```
